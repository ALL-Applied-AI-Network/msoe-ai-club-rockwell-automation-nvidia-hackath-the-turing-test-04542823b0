# Card 9 Scoring Rubric: Cosmos Physical AI Explanations

This rubric defines the scoring criteria for evaluating explanations generated by NVIDIA Cosmos 3 Nano Reasoner for flagged carryover vials on Fluid Mixing Station 3.

---

## 1. Evaluation Rules

- **Scorer:** A teammate who did not write the prompt evaluates each response.
- **Answer key:** The scorer scores the **first repeat** of each of the 8 flagged first vials (vials 4, 7, 10, 16, 19, 22, 25, 28) from `outputs/card9/explanations.csv`.
- **Repeat consistency:** Also verify how many of the 3 repeats give identical decisions (`matches_recipe` and `likely_cause`).
- **Consistent with evidence, not detection:** Because the prompt gives Cosmos our verdict and the previous recipe, criteria 1 and 2 test whether Cosmos stays consistent with the evidence, not whether it detects carryover by itself (Card 3b tested detection). Report the score as 'N of 8 explanations fully correct', never as detection accuracy.
- **Scoring standard:** An explanation is scored as **CORRECT** (1) if and only if **all five criteria** below are satisfied. If any criterion fails, the explanation is scored as **INCORRECT** (0), and the failing criterion number is logged in `annotations/card9_scores.csv`.

---

## 2. Five Scoring Criteria

An explanation is **CORRECT** only if:

1. **`matches_recipe` is `false`:**
   - The vial is discolored and failed the color check ($\Delta E_{2000} > 5.0$).
   - Cosmos must correctly judge that the vial does NOT match the clean recipe reference (Image 2).

2. **Names the previous recipe:**
   - Names the previous recipe: by its number (e.g. 'Recipe 6') or explicitly as 'the previous recipe' together with what it contained. Naming only a dye that both recipes contain does not count.

3. **Attributes the cause to leftover residue in the shared path or nozzle:**
   - The explanation must correctly attribute the discoloration to physical carryover: leftover fluid/dye from the previous recipe remaining in the single shared dispensing line, pipe, manifold, or nozzle and mixing into the beginning of the new fill.

4. **Action invents nothing (no unverified facts or claims):**
   - The recommended operator action must be grounded strictly in the provided station facts.
   - **FAIL criteria:** Any invented business or physical numbers (e.g., made-up dollar scrap costs, made-up pipe lengths, invented flush volumes) or false claims that a specific flush protocol has been proven/tested on this line (our dataset contains no flush runs; a flush requires plant manager approval).
   - **Acceptable actions:** Flagging the vial for inspection/quarantine, checking the line, reordering queue, or requesting a clear line flush with supervisor/plant approval.

5. **`observed_color` is a fair visual description of Image 1:**
   - The human scorer inspects the vial crop (`outputs/card3b/crops/vial<NN>.png`) by eye.
   - The text in `observed_color` must be an accurate description of the visible liquid appearance (e.g., for vial 7: "green", "greenish-blue", "olive green", or "dark teal"; not "pure orange", "bright red", or "clear blue").
